# Package index

## MCTQ

A complete toolkit for processing the Munich ChronoType Questionnaire
(MCTQ) in its three versions: standard, micro, and shift.

- [`fd()`](https://docs.ropensci.org/mctq/reference/fd.md)
  **\[maturing\]** : Compute MCTQ work-free days
- [`so()`](https://docs.ropensci.org/mctq/reference/so.md)
  **\[maturing\]** : Compute MCTQ local time of sleep onset
- [`gu()`](https://docs.ropensci.org/mctq/reference/gu.md)
  **\[maturing\]** : Compute MCTQ local time of getting out of bed
- [`sdu()`](https://docs.ropensci.org/mctq/reference/sdu.md)
  **\[maturing\]** : Compute MCTQ sleep duration
- [`tbt()`](https://docs.ropensci.org/mctq/reference/tbt.md)
  **\[maturing\]** : Compute MCTQ total time in bed
- [`msl()`](https://docs.ropensci.org/mctq/reference/msl.md)
  **\[maturing\]** : Compute MCTQ local time of mid-sleep
- [`napd()`](https://docs.ropensci.org/mctq/reference/napd.md)
  **\[maturing\]** : Compute MCTQ nap duration (only for
  MCTQ\\^{Shift}\\)
- [`sd24()`](https://docs.ropensci.org/mctq/reference/sd24.md)
  **\[maturing\]** : Compute MCTQ 24 hours sleep duration (only for
  MCTQ\\^{Shift}\\)
- [`sd_week()`](https://docs.ropensci.org/mctq/reference/sd_week.md)
  **\[maturing\]** : Compute MCTQ average weekly sleep duration
- [`sd_overall()`](https://docs.ropensci.org/mctq/reference/sd_overall.md)
  **\[maturing\]** : Compute MCTQ overall sleep duration (only for
  MCTQ\\^{Shift}\\)
- [`sloss_week()`](https://docs.ropensci.org/mctq/reference/sloss_week.md)
  **\[maturing\]** : Compute MCTQ weekly sleep loss
- [`le_week()`](https://docs.ropensci.org/mctq/reference/le_week.md)
  **\[maturing\]** : Compute MCTQ average weekly light exposure
- [`msf_sc()`](https://docs.ropensci.org/mctq/reference/msf_sc.md)
  **\[maturing\]** : Compute MCTQ sleep-corrected local time of
  mid-sleep on work-free days
- [`sjl()`](https://docs.ropensci.org/mctq/reference/sjl.md)
  [`sjl_rel()`](https://docs.ropensci.org/mctq/reference/sjl.md)
  **\[maturing\]** : Compute MCTQ social jetlag
- [`sjl_sc()`](https://docs.ropensci.org/mctq/reference/sjl_sc.md)
  [`sjl_sc_rel()`](https://docs.ropensci.org/mctq/reference/sjl_sc.md)
  **\[maturing\]** : Compute Jankowski's MCTQ sleep-corrected social
  jetlag
- [`sjl_weighted()`](https://docs.ropensci.org/mctq/reference/sjl_weighted.md)
  **\[maturing\]** : Compute MCTQ absolute social jetlag across all
  shifts
